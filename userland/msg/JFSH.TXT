JFS0001H: EXPLANATION: The partition is too small to hold a JFS file system.

ACTION: Make the partition larger, or format some other partition.
JFS0002H: EXPLANATION: The JFS log asked for is too big for the partition.

ACTION: Ask for a smaller log in the format options, or make the
partition larger.
JFS0003H: EXPLANATION: JFS cannot be used on a drive whose adapter is unable to
reach physical memory above 16 megabytes.

ACTION: Use a better adapter, or format the volume as HPFS or FAT.
JFS0004H: EXPLANATION: JFS can be put only on an LVM partition, and the
partition given is not one.

ACTION: Make the partition an LVM partition, or format some other
partition.

ACTION: Run CHKDSK with the /F parameter.
