SYS0002H: EXPLANATION: No file with the given name exists in the current

SYS0004H: EXPLANATION: The limit on open files has been reached.

ACTION: Let another program finish, then run the command again.
SYS0005H: EXPLANATION: Possible causes:
1. The file has the read-only attribute.
2. The file, directory, named pipe, queue or semaphore is shared and
   is being used by someone else right now.
3. Your user account lacks the rights needed for this resource or
   action (for example, on a network server).
4. The file name is wrong.
5. A DOS program tried to open a file whose extended attributes are
   marked as required (Need EA is set).

ACTION: Fix the cause and try again:
1. Clear the read-only attribute with the ATTRIB command.
2. Wait a while and try to use the resource again.
3. Log on with an account that has the needed rights, or ask the
   administrator of the resource to grant them.
4. Use the correct file name.
5. Handle the file with an OS/2 program instead.

SYS0007H:
SYS0008H: EXPLANATION: Memory has run out.  When swapping is enabled, the
swap file may have filled its disk, or reading or writing the swap
file may have failed.

ACTION: Try any of these, then run the command again:
o  Close some programs.
o  Lower the values of BUFFERS=, TRACEBUF=, DISKCACHE=, THREADS= or
   RMSIZE=, or make a DEVICE=VDISK.SYS disk smaller, in CONFIG.SYS,
   and restart the system.
o  Delete files you no longer need from the swap file's disk and
   restart the system.
o  Add more memory to the computer.
o  Check the swap file's disk for errors.

SYS0015H: EXPLANATION: Possible causes:
1. There is no such drive.
2. The drive letter is wrong.
3. RESTORE was pointed at a redirected (network) drive.
4. RESTORE was pointed at a read-only drive.

ACTION: For causes 1 and 2, give the correct drive letter and try
again.  For causes 3 and 4, choose another target: RESTORE cannot
write to redirected or read-only drives.
SYS0016H: EXPLANATION: Possible reasons the directory could not be removed:
1. It does not exist, or its name is misspelled.
2. It still holds files or subdirectories.
3. It is the current directory of a running session (on any drive,
   even one that is not that session's current drive).
4. Its name matches a reserved OS/2 device name.

ACTION: Fix the cause and try again:
1. Give the correct directory name.
2. Delete or move everything inside the directory first.
3. Switch every session that may be in it to another directory
   with the CD (CHDIR) command.
4. If an installed device has the same name, remove that device.
SYS0017H: EXPLANATION: Moving or renaming cannot take a file to another
disk drive.

ACTION: Use the same drive in the old and new names, or copy the
file to the other drive instead.

ACTION: For removable media, check that the right diskette is in the
drive or turn off its write protection, then try again.  An XDF
(eXtended Density Format) diskette stays write-protected until it is
formatted again.

1. The device is empty or not ready.
2. For a COMn port: its device driver is not loaded, or the port was

ACTION: Fix the cause and try again:
1. Put a diskette in the drive and close the door, or wait until the
   drive is free.
2. a. Make sure CONFIG.SYS has a DEVICE=COM.SYS statement.

      about COMn while it starts.
   c. Run MODE COMn at a command prompt to check that the port is
      there.
3. Make sure the computer actually has a COMn port.

ACTION: What to do depends on where the swap file (SWAPPER.DAT) is.

Swap file on drive C: (where it is put by default):
  1. Start the system from an OS/2 or DOS startup diskette.
  2. Copy the files on drive C: that are not part of OS/2 to
     diskettes.
  3. Install OS/2 again and choose to format drive C:.
  4. Copy back the files you saved in step 2.

Swap file on some other drive:
  1. Start the system from an OS/2 or DOS startup diskette.
  2. Change the SWAPPATH line in CONFIG.SYS so the swap file is on
     drive C:, for example SWAPPATH=C:\OS2\SYSTEM 512.
  3. Start OS/2 from the hard disk as usual.
  4. Recover from the error if needed; the drive with the bad
     sector may have to be formatted again.
  Optionally:
  5. Copy all files on the drive with the bad sector to diskettes.
  6. Format that drive.
  7. Copy back the files you saved in step 5.

If that does not help:
  1. Choose the format option on the Hardware Reference Diskette.
  2. Do a low-level format of the whole hard disk.
  3. Install OS/2 again.

If that does not help either:
  1. Put in a new hard disk.
  2. Install OS/2.
  3. Copy back all the files you saved.
